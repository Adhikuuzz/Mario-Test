# 🍄 Mini Mario — Browser Platform Game

A simple **Mario-style 2D platform game** built using **HTML, CSS, and JavaScript**.

The game runs directly in your web browser, with no frameworks or external libraries required.

## 🎮 Features

* 🏃 Player movement
* 🦘 Jumping and gravity physics
* 🧱 Platforms and obstacles
* 🪙 Collectible coins
* 👾 Enemy characters
* ❤️ 3 lives
* ⭐ Score system
* 🏁 Goal/finish flag
* 📜 Side-scrolling camera
* 🔄 Restart functionality
* ☁️ Animated-style game background

## 🕹️ Controls

| Key                 | Action       |
| ------------------- | ------------ |
| `A` / `←`           | Move Left    |
| `D` / `→`           | Move Right   |
| `W` / `↑` / `Space` | Jump         |
| `R`                 | Restart Game |

## 🛠️ Technologies Used

* **HTML5** — Game structure and Canvas
* **CSS3** — Page styling
* **JavaScript** — Game logic, movement, collision detection, enemies, coins, scoring, and physics

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/mini-mario.git
```

### 2. Open the project

Go into the project folder:

```bash
cd mini-mario
```

### 3. Run the game

Open:

```text
mario.html
```

in any modern web browser.

No installation or server is required.

## 🎯 How to Play

1. Start the game.
2. Use `A/D` or the arrow keys to move.
3. Jump across platforms.
4. Collect coins to increase your score.
5. Jump on enemies to defeat them.
6. Avoid falling off the platforms.
7. Reach the flag at the end of the level to win.
8. You have **3 lives**.
